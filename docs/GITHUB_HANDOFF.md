# GitHub handoff

The repository is intended to remain private under the `Obmore` GitHub account.

## Remaining owner action

Inviting `kozmalaszlo2` as a collaborator is intentionally not automated. After
publication, the project owner can complete that step in GitHub under:

```text
Repository Settings -> Collaborators -> Add people
```

Grant only the access level required for the assignment and verify the invitation
before sharing any repository content elsewhere.
